FOR GROK BOT OWNERS

Your bot. Your PC.
You hold the switch.

Choose one Windows app window. Set a timer or a dated phone window. Let an approved bot work while you are away — without handing it the whole desktop.

Download Windows host Setup guide

Development baseline. Unsigned portable build. Not an official xAI product. BotDesk does not sign into Grok.

BEFORE YOU LEAVE

Three steps on the PC. The switch stays yours.

  1. 01
    Pair this PC

    Deploy your private Cloudflare relay, paste the host pairing JSON, and save. Tokens stay on this Windows profile, encrypted by the OS.

  2. 02
    Choose one window

    Refresh and select Edge, Chrome, Firefox, Notepad, or opted-in Roblox Studio. Screenshots and clicks stay inside that window.

  3. 03
    Arm from the phone

    Go live now, or schedule one dated window such as 6 AM–6 PM. STOP on the PC or Ctrl+Shift+F12 cancels access immediately.

OWNER SWITCH

Timed access, not always-on remote desktop

GO LIVE defaults to eight hours and caps at twelve. A phone schedule is one dated window, not a daily recurrence. OFF, pause, expiry, or a dropped relay connection stop commands.

BOT TOOLS

MCP controls for a compatible runner

Status, screenshot, snapshot, window list, focus, click, move, drag, type, keys, scroll, clipboard, and recording. One bot lease. Fresh snapshot required before input.

HARD STOPS

No UAC, no full desktop, no silent queue

Elevated windows, password fields, and unknown desktop integrity fail closed. Overlapping commands are rejected. An input already delivered to Windows cannot be undone.

HONEST STATUS

This is a controlled pilot, not a store launch.

  • Windows host — portable exe you build or download from GitHub Releases. SmartScreen will warn until it is signed.
  • Relay — you deploy the included Cloudflare Worker. There is no shared multi-tenant BotDesk cloud.
  • Website — this page. Source and docs live in the public repo.
  • Live proof — automated tests pass; unattended phone→PC runs still need your own acceptance check.
