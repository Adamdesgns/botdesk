## Product page

BotDoor lets the owner of a Windows PC grant a bot access for a limited time using a separately installed companion and private relay. The owner selects the scope and can pause or stop access. Windows must remain awake and signed in. PC access limits editing actions; selected-window access permits guarded input. Closing windows can lose unsaved work, and launching programs can have side effects. BotDoor cannot unlock Windows, operate UAC or promise recovery of a frozen program. It is independent software and is not endorsed by OpenAI or xAI.

## Privacy draft

BotDoor processes host identifiers, connection/access state, session timing, bot identity, command names and arguments, and approved window images or accessibility labels when requested. Window metadata may include titles, process identity and executable paths. Selected-window input may contain the text the user asks to enter. Clipboard read and local recordings are available only within the permitted host policy. Screens and clipboard can contain personal information; use BotDoor only in apps and data you intend to share with your AI runner.

The Windows companion executes permitted actions and stores configuration, local audit records and local recordings. Saved companion credentials use Windows-backed encryption. The relay verifies bot/owner/host authorization and forwards command requests/results. The bot runner and its AI provider receive the requested results; the relay hosting provider processes network traffic. The plugin package does not contain credentials or read unrelated private configuration. A published service must identify its operator and hosting/data recipients explicitly.

The owner can stop/pause access, cancel schedules and manage the host's access scope. Local emergency STOP requires local unlock before remote rearming. Stopping access prevents subsequent authorized capture but cannot retract results already delivered to a runner. Recordings are not automatically uploaded by the companion. Audit files and recordings currently remain locally until removed; no automatic purge promise is made.
